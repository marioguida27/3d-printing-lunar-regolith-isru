# DLP 3D Printing of Lunar Regolith Simulant for ISRU

**Aerospace Technologies Laboratory, Politecnico di Milano (A.Y. 2024/2025), Group 5**

This is a lab project on manufacturing ceramic parts from **LHS-1 lunar regolith simulant** with **DLP vat photopolymerisation**, aimed at In-Situ Resource Utilisation (ISRU) on the Moon. We designed and printed gyroid-lattice cylinders and flexural bars, then sintered them. The report covers four parts:

- R.A.M.S. analysis of the printing process
- shrinkage and microstructure analysis (SEM, MATLAB/ImageJ)
- mechanical testing to ASTM C1161 and C1424
- root-cause analysis of cracking
